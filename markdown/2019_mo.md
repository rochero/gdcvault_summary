## Mobile Indie Game Dev Stories
- **Speaker:** Jeff Laird, Serban Serafimescu, Graham Pentheny (Runaway, Dream Primer, Spry Fox)
- **Duration:** 43 分钟
- **Category:** Mobile Summit
- **Video Page:** https://www.gdcvault.com/play/1025932
- **Slide Page:** https://www.gdcvault.com/play/1026386
- **Custom ID:** 1025932

### Overview
Postmortems do a disservice to the industry because a) they assume a game is done when released (when no game today ends after its first release), and b) they mostly talk about the same issues ("we crunched a lot!", "it was much harder than we thought!", etc). So this session asks 3 mobile game developers with great games to come talk about some specific aspects of the design or the production process that made their game unique. This year the speakers will discuss incremental updates to improve monetization in 'Furistas Cat Cafe', iteration design in 'Alphabear 2', and how the developers of 'Eternium' did not give up and after many releases over the course of many years they have become one of the most popular action rpg games on Android.

### Content Summary
[TLDR]
三款独立手游实战复盘，强调通过迭代设计与良心变现换取长线用户留存与利润，拒绝杀鸡取卵。
[Background]
三位来自 SpryFox、Runaway Play 和 Dream Primer 的主创，分享了小团队如何在买量成本高企的当下，利用有限资源靠产品力和数据分析实现增长。
[Recaps]
SpryFox 团队把《Alphabet Bear》从一代做到二代，核心思路是**增量式与迭代式设计 (Incremental and Iterative Design)**。他们先简化了计分规则让玩家看懂策略，又加了“亲和度 (Affinity)"机制逼着玩家去收集各种功能的熊，而不是卡在一两只。最绝的是，他们用代码模型模拟了整个**元游戏进程 (Metagame Progression)**，省掉了昂贵的**软发布 (Soft Launch)**资金就能验证数值。最终他们的**生命周期价值 (LTV)**提升了七倍，证明了好玩法配合合理**变现 (Monetization)**才能长久赚钱。

Runaway Play 的经历比较惨，《For Easter's Cat Cafe》因为赶进度提前全球上线，导致各项**关键绩效指标 (KPI)**烂得一塌糊涂。他们回炉重造后，主要动了两个手脚：一是简化了**软货币 (Soft Currency)**获取和商店逻辑，让玩家觉得钱花在刀刃上；二是提高了视频广告的观看频次。虽然没彻底解决**留存 (Retention)**问题，但至少数据稳住了，血泪教训是千万别为了赶 Deadline 跳过打磨环节。

Dream Primer 做的《Eternium》则是靠死磕品质起家的。他们一开始只有三个人，没钱投广告，所以死磕用户体验。比如找到玩家操作时的“困惑时刻”并消除它，甚至专门做了 A-B 测试 (A-B Testing) 来优化商店图标，把安装转化率硬生生拔高了。靠着这种不贪婪、重体验的态度，他们实现了三十倍的用户增长，证明了只要游戏足够好玩，**口碑效应 (Word of Mouth)**比硬砸钱更有效。

三家虽然赛道不同，但核心都在一个理上：别总想着割韭菜，要把游戏本身打磨得让人愿意留下来。

## Artisanal Procedurality in Losswords
- **Speaker:** Alexander King, Eric Zimmerman (Independent, NYU Game Center, King, Playmatics, King)
- **Duration:** 0 分钟
- **Category:** Mobile Summit
- **Video Page:** 
- **Slide Page:** https://www.gdcvault.com/play/1026341
- **Custom ID:** 1026341

### Overview
There are many game design topics that don't require an hour to discuss, but can be useful as tips, or food for thought, for seasoned mobile game designers. Part microtalk, part design review, the MGDN is the session at the GDC Mobile Summit where experienced mobile game designers pick somebody else's game, or a trend in mobile game design, and dissect it. This year, this session will discuss procedurally generated content using books in the public domain, fashion as an element of gameplay in a role-playing game, and players' feelings when they make purchases in mobile games.

### Content Summary
[TLDR]
核心观点是：想要游戏无限重玩且高品质，不能纯靠堆料，得靠精心策划的剧本选择与谜题缩放体系来平衡工作量。

[Background]
独立开发者常头疼如何让游戏既有深度又能反复玩，同时不把制作团队累垮。这期干货适合想解决“内容量 vs 质量”矛盾的团队参考，专门教怎么用有限资源撬动玩家的高期待。

[Recaps]
这段内容主要拆解了游戏设计里一组经典的矛盾关系。玩家想要的往往是**直接控制 (Direct Control)** 角色的爽快感、**无限 (Infinite)** 的变化体验，同时还要保证**高品质 (High Quality)** 的内容质量和足够的**意外性 (Unexpected)**。但在实际落地的时候，这几样东西放在一起就是个大坑，因为做到高质量和多样性几乎必然意味着**人力密集型 (Labor-intensive)** 的开发投入。更致命的是，这种传统方式往往**无法扩展 (Doesn't scale)**，一旦项目规模稍微大一点，工作量就会指数级爆炸，导致项目烂尾或者删减大量内容。

为了解决这个问题，演讲者给出了一套“以少胜多”的实操方案。核心逻辑不是盲目生产内容，而是在叙事上做**图书策展 (Book Curation)**，像编辑选书一样筛选现有素材；再通过**章节选择 (Chapter Selection)** 机制让系统自动组装最佳体验路径。而在玩法设计上，建议采用**谜题缩放 (Puzzle Scaling)** 策略，即根据玩家水平动态调整**难度递进 (Difficulty Progression)**，而不是为了增加复杂度去硬造一堆新的**谜题关卡 (Puzzle Levels)**。这种思路能有效降低美术和策划的重复劳动。

最后的重点落在了体验优化上，强调要在有限的流程里埋入足够多的**TWISTs**（剧情转折），让玩家在每个关键节点都能感受到惊喜，从而大幅提升游戏的**可重玩性 (Replayable)**。整场分享其实就是在告诉同行：别执着于做虚假的无限内容，要在结构化框架内打磨关键节点，用小成本实现高沉浸感的体验闭环。对于预算紧张但追求口碑的小组来说，这套方法论绝对比砸钱请人堆素材要靠谱得多。

## Love Nikki & How to Fight Gender Essentialism with Formalism
- **Speaker:** Nicholas Fortugno (Playmatics)
- **Duration:** 0 分钟
- **Category:** Mobile Summit
- **Video Page:** 
- **Slide Page:** https://www.gdcvault.com/play/1026303
- **Custom ID:** 1026303

### Overview
There are many game design topics that don't require an hour to discuss, but can be useful as tips, or food for thought, for seasoned mobile game designers. Part microtalk, part design review, the MGDN is the session at the GDC Mobile Summit where experienced mobile game designers pick somebody else's game, or a trend in mobile game design, and dissect it. This year, this session will discuss procedurally generated content using books in the public domain, fashion as an element of gameplay in a role-playing game, and players' feelings when they make purchases in mobile games.

### Content Summary
[TLDR]
别光靠剧情立人设，得通过游戏机制（Formalism）的数值循环，让女性角色的能力成长直接打破性别刻板印象。

[Background]
现在好多游戏对女性角色的刻画还是老一套，要么花瓶要么被保护对象，这就叫陷入了“性别本质主义”的陷阱。这场演讲适合所有做系统设计的主策看，作者 Nick Fortugno 拿《Love Nikki》当样本，想教大伙儿怎么用规则和数值去解决审美偏见问题，而不是只停留在嘴上喊口号。

[Recaps]
咱们先聊聊痛点，现在很多作品搞女权或者强调女性力量，容易流于表面。Nick 上来就提了个概念，叫“性别本质主义 (Gender Essentialism)"，简单说就是大家潜意识里觉得女性就该柔弱或依附他人。他提出的解决方案是“形式主义 (Formalism)"，意思就是别光靠过场动画讲故事，得靠游戏本身的规则设计来传递态度。这招高就高在，机制比台词更骗不了人，玩家玩得爽的时候，观念自然就接受了。

再看案例《Love Nikki》，表面上看是个换装游戏，但 Nick 剖析了它的深层逻辑。普通换装只是好看，但这游戏把衣服变成了战斗力。幻灯片里那几个词很能说明问题：“Improvement (提升)”、“Defeat (击败对手)”和“Rewards (奖励)”。玩家在选装束时，其实是在配置数值装备。穿得漂亮不是为了给别人看，是为了在 PVP 或闯关里打出更高的伤害。这种设计直接把“美丽”转化为了“权力”，彻底扭转了女性物品作为被观赏对象的地位。

最后总结一下这套打法的核心。Nick 展示了一个闭环：“ Abilities (能力)”对抗“Opponent (对手)”，赢了拿“Rewards (奖励)”再来“Improve (变强)”。这就是典型的数值成长循环，但他把这个循环包装成了女性向的换装体验。这说明硬核的游戏性不一定非要跟男性向绑定，只要你在底层规则上承认女性的选择能带来实质性的力量增长，所谓的性别歧视在游戏逻辑里就不攻自破。这不仅是技术活，更是一种设计哲学的胜利。

## Monetization Design: The Dark Side of Gacha
- **Speaker:** Vladimir Krasilnikov (Pixonic)
- **Duration:** 31 分钟
- **Category:** Mobile Summit
- **Video Page:** https://www.gdcvault.com/play/1025720
- **Slide Page:** https://www.gdcvault.com/play/1026346
- **Custom ID:** 1025720

### Overview
This session will talk about aggressive monetization. It's assumed that nudging players and pressuring them into making in-game purchases affects the future of a game poorly. However, business believes in numbers, not vague threats of postponed doomsday.Speaker Vladimir Krasilnikov will discuss how a drastic change of in-game economy in 'War Robots' brought amazing financial results in the beginning, but upset a large part of the audience, so caused some key metrics to decline. Also, he'll show how his team fixed the situation and kept everyone pleased on a project with more than $5 million monthly revenue.

### Content Summary
[TLDR]
牺牲短期爆发的暴利，选择长期的稳定增长，才能换来玩家信任和团队长久的健康发展。

[Background]
作为《War Robots》背后的俄罗斯开发者 Vlad，他在 GDC 分享了自己工作室从“疯狂敛财”到“长期主义”的血泪转型。这篇演讲主要解决手游如何在盈利与口碑之间找平衡的痛点，特别适合正在为营收波动和玩家吐槽头疼的制作人参考。

[Recaps]
兄弟们，今天咱们不整虚的，聊聊怎么在游戏里搞钱还不招人恨。Vlad 直接把策略分成了两派：一个是“热浪模式 (Hype Model)”，就像过年抽奖，开局爆炸，随后速朽；另一个是“价值增长模式 (Value Growth Model)”，像是存钱罐，前期慢点但后期稳。这其实就是个棉花糖测试，你是想马上吃完手里的一个，还是忍一忍等第二个更大的。Pixonic 刚成立时急于回笼资金砸买量，果断选了前者，但这中间踩了不少坑。

先说那个“热浪模式”，核心手段就是搞“扭蛋机制 (Gacha)”。咱们把这玩意儿理解成“巧克力蛋”，不管开出啥玩具，至少巧克力的部分总是有用的。为了安抚玩家运气，我们还用了“伪随机机制 (Illusion of Randomness)"，让你觉得每次都能开出好东西。但这东西有个致命缺陷，参考当年《星球大战》的丑闻，当玩家发现是在被掏空钱包时，反噬很严重。虽然数据上收入飙升，但社区口碑崩了，开发团队甚至变得畏手畏脚，怕再出新玩法就被喷死。

后来我们痛定思痛，转向了“动态报价系统 (Wild Offers System)"。这招有点像动态打折，系统根据你的行为生成 Offer，哪怕混进几个干扰项来迷惑玩家，只要最终能精准匹配需求就行。虽然这玩意对后端数据和算力要求极高，还要分集群做分析，但它带来的收入曲线平滑得让人感动。最重要的是，团队士气回升了，商店评分也涨了，不再是大起大落的过山车，而是稳步向上的台阶。

最后总结几点干货，别让“扭蛋”背锅，关键看你怎么设计。如果你想快钱就冲热浪，想长线就走价值增长。货币设计上，我们用“季节限定钥匙卡 (Seasonal Key Cards)”防止玩家囤积垃圾币，过期还能兑换其他价值。还有一点，别小瞧“鲸鱼用户 (Whales)"，大部分真金白银还是这群愿意花钱的人出的。记住，游戏不仅仅是冷冰冰的数据，玩家的情绪也是宝贵的资产，长期主义才是真的香。

## Top 3 Mistakes of 'Angry Birds 2'
- **Speaker:** Mans Wide (Rovio)
- **Duration:** 21 分钟
- **Category:** Mobile Summit
- **Video Page:** https://www.gdcvault.com/play/1025934
- **Slide Page:** https://www.gdcvault.com/play/1026458
- **Custom ID:** 1025934

### Overview
For every successful game, there are plenty of mistakes made along the way. Mans Wide, product lead of 'Angry Birds 2', made a lot of bad calls during the production of "the biggest sequel ever made". This session will share the biggest mistakes made and what the 'Angry Bird 2' team (hopefully) learned from them. In this session, you will hear 3 important lessons that took Mans over 4 years to learn. What were the mistakes, what were the actions they took to fix them, and what were the lessons learned? Mans will answer these questions.

### Content Summary
[TLDR]
做手游别瞎折腾运营套路，核心玩法不够好玩，再好的数值也救不了留存率。

[Background]
Rovio 商业化总监复盘《愤怒的小鸟 2》转型 Free To Play (F2P) 的血泪史，直指产品过度关注数据而忽视核心体验的误区，适合负责 F2P 游戏长线运营的产品与设计师避雷。

[Recaps]
第一个错误是“过度喂养金鱼”。演讲者自嘲属于花钱少的“金鱼玩家”(Goldfish)，但团队总想把精力花在这些人身上。这就好比平均财富计算时混入了世界首富，导致数据严重失真。实际上，大部分营收靠的是高付费的大 R (Whales)。如果拿着“人均生命周期价值 (LTV) $10"的平均数瞎指挥，会误以为所有人都该付这点钱，实际上大部分人可能分文不取。正确的思路是别死磕小额付费转化，而是挖掘大 R 的潜力，让他们多掏一点比求小白买单划算得多。

第二个错误是“直升机式育儿”。刚立项时总怕功能太多吓跑用户，首发版本做得极简，恨不得把所有按钮都删了。结果上线后发现玩家根本没那么娇气，反而觉得内容空洞留不住人。后来被迫补全竞技场、日常任务、换装系统等大量深度内容，数据才回正。这说明团队不该过度保护新手，该开放的功能越早给越好，否则等到用户跑了再补课，损失的根本是机会成本。

第三个错误最扎心：“只有工作没有乐趣”。为了修补 `留存率 (Retention)`，团队常年做 A/B 测试 (A/B Test)，搞签到日历、公会社交各种运营活动，结果收效甚微。直到意识到那些要流失的人根本不在乎什么奖励，只想图个乐子。后来试着把关卡设计做得更有趣，数据直接起飞。结论很简单：别把游戏当成复杂的系统工程，先让玩家玩得开心，别本末倒置，毕竟这是个游戏，好玩才是硬通货。

## The Year in Mobile Games: 2019 Edition
- **Speaker:** Steve Meretzky, Dave Rohrl, Juan Gril (Independent, Mobile Game Doctor, Xbox Game Studios)
- **Duration:** 58 分钟
- **Category:** Mobile Summit
- **Video Page:** https://www.gdcvault.com/play/1025850
- **Slide Page:** https://www.gdcvault.com/play/1026371
- **Custom ID:** 1025850

### Overview
Dave Rohrl, Juan Gril, and Steve Meretzky continue their annual recap of the mobile game industry's highlights, surprises, and trends. This heavily-researched must-see presentation traditionally kicks off the Mobile Game Summit, and offers a great industry-wide overview to set the stage for the next two days of mobile games sessions.

### Content Summary
[TLDR]
移动端爆款不再靠简单移植主机内容，而是深度绑定新生代玩家的社交圈层与长期精细化运营。

[Background]
基于 App Store 十周年数据复盘，旨在为开发者揭示在流量红利消退后，如何通过洞察用户代际变化、调整产品策略以及在红海中找到生存之道。

[Recaps]
首先得看 Roblox 的成功逻辑，这可不是什么一夜暴富的神话。这款产品花了整整十年打磨，真正爆发是靠抓住了孩子天生的“群体效应 (Pack Animal Effect)"。当朋友圈都在玩的时候，为了不被孤立，孩子们会疯狂安利。这说明光有个好点子没用，你得把社交链路跑通，熬过漫长的冷启动期，等热度达到临界点才能形成病毒式传播。这种长线主义的经验值得所有人学习，而不是只盯着当下的功能迭代。

接着聊聊 Fortnite，它能在手机上打败那么多硬核主机游戏，核心原因是精准拿捏了未成年人这个群体。年轻人可能没钱买 PS4 或 Xbox，手机就成了他们参与主流社交游戏的唯一入口。虽然“大逃杀 (Battle Royale)"在手机上的按键操作有点别扭，但这反而成了门槛。再加上 Epic 做得极好的 Live Operations (运营活动)，比如办虚拟演唱会，直接把游戏变成了类似 MTV 的新媒体。想跟风做这类游戏的兄弟，先掂量下你能不能搞定这群爱攀比又缺预算的用户。

关于业内常谈的“换皮抄袭”问题，这次演讲给了个反直觉结论。通常认为模仿必死，比如那些《Clash of Clans》的克隆体都没戏。但 Matchington Mansion 靠着 Gardenscapes 的同类型题材照样能分一杯羹。关键区别在于题材微调（室内装修 vs 花园）和品类容忍度（消除类游戏可以多开）。反观《Brawl Stars》，则是经过了漫长的 Soft Launch (软发布) 周期，推倒重来两三次才换来现在的稳定表现。这提醒我们，如果是高兼容度的品类，两个高质量竞品有时可以共存。

最后得说说技术趋势的变化。以前大家觉得手机上用不好复杂操作，现在发现新一代用户对“虚拟摇杆 (Virtual Joystick)"的接受度高了很多。除了这些头部大作，演讲者也特意推荐了几个像 Monster Merge 或者 Helix Jump 这种不起眼的小品游戏。有时候真正的创新不在大块头里，而在于这些小细节的打磨。总之，别总盯着大厂动作，多关注用户的需求变化和代际差异，这才是做游戏长青的关键。

## Not Always by the Book: Successful Against the Odds
- **Speaker:** Alexander Pavelek (Pixel Federation)
- **Duration:** 30 分钟
- **Category:** Mobile Summit
- **Video Page:** https://www.gdcvault.com/play/1025936
- **Slide Page:** https://www.gdcvault.com/play/1026516
- **Custom ID:** 1025936

### Overview
Having day 1 retention under 20% means, by the book, that you should kill your game as soon as possible. - **Speaker:** Rob Giusti (Niantic)

### Overview
In July 2016, Niantic Inc. launched 'Pokemon GO', which grew into a worldwide phenomenon. However, it was not until December 2018 when the development team added a directly competitive, player-versus-player feature. In this session, Engineering Combat Lead Rob Giusti will discuss why Niantic chose to build this new feature at this point in the game's lifecycle, and what decisions were made to make the feature true to its roots in the Pokemon franchise, while also creating a foundation for further game development in a live, growing game.

### Content Summary
[TLDR]
通过免费公平的对战设计和分级联赛，在不破坏游戏生态的前提下激活老玩家并延长游戏时长。

[Background]
Niantic 资深工程师揭秘《精灵宝可梦 GO》实装训练家对战 (Trainer Battles) 背后的设计逻辑。重点在于解决用户流失和玩法单一痛点，为移动 RPG 如何实现高质量长线运营提供了宝贵的实战范本。

[Recaps]
Niantic 的大佬这次真金白银地掏了干货，讲讲咋样在《精灵宝可梦 GO》里塞进实时对战 (Real-time Combat)。说实话，这项目不是为了搞钱，核心 KPI 就是 DAU (日活跃用户数) 和在线时长，想把那些弃坑的老哥拉回来。他们特别反感那种“有钱就能赢” (Pay-to-win) 的设计，怕把社区玩崩了。老板们算过账，只要人够多，维持同样的付费转化率，收入照样猛涨，所以干脆不搞内购压制，纯靠体验留人。

玩法机制这块也花了不少心思。为了照顾手机端操作，他们放弃了传统的回合制 (Turn-based)，改为即时战斗，防止玩家切后台挂机。针对新老战力差距大的问题，搞了三档战斗联盟 (Battle Leagues)，按 CP (Combat Power) 等级封顶，菜鸟有菜鸟局，大佬有大佬的爽感。还加了个保护护盾 (Protect Shields) 机制，虽然能防大招但数量有限，逼得大家不能无脑砸技能，得赌对方动向。为了以后能继续加东西，前期还做了大量的原型测试 (Prototyping)，保证技术底座能扛得住后续迭代。

最后说说奖励机制，这可是个细节鬼才操作。无论输赢，奖励都在同一个奖励掉落表 (Loot Table) 里，全是星尘 (Stardust) 和进化道具，主打一个“参与就有收获”。新手教学没整那些枯燥的流程，直接派 NPC (非玩家角色) 陪练，随便浪也不扣资源。线上匹配全靠扫码，线下聚会方便得很，连远程 PK 都要求好友互动满一个月，有效遏制了恶性刷战绩。这波做完之后，游戏数据和社区口碑齐飞，证明只要懂用户，不瞎折腾内购也能把游戏做火。

## To Affinity and Beyond: Lessons Learned Mapping the Mobile Games Market
- **Speaker:** Ishai Smadja (King)
- **Duration:** 22 分钟
- **Category:** Mobile Summit
- **Video Page:** https://www.gdcvault.com/play/1025854
- **Slide Page:** 
- **Custom ID:** 1025854

### Overview
Ensuring your game stands out is a constant challenge.To guide the creation of blockbuster games, developers really need to understand their players and their preferences. At King, they've found that affinity data can be a powerful tool to help achieve this and can have a big impact on the success of games. They've mapped the mobile gaming market based on affinity and how this relates to audience preferences. But what is it that they develop an affinity for? Can game designers use that information to market games better or even decide what kinds of games to make? This session explores those questions!

### Content Summary
[TLDR]
别瞎猜市场，用“亲和力”数据画地图，拆解核心、元层等四大积木，才能真正摸透玩家心思做对游戏。

[Background]
King 的大佬分享说，之前做了一款寻物解谜游戏 (Hidden Object Game) 因为没机会被砍了。为了找新的混合玩法 (Hybrid) 机会，他们发现海量数据根本没法肉眼看，于是做了个可视化地图。这个总结适合所有想用数据驱动决策，尤其是想知道玩家到底喜欢啥的开发者。

[Recaps]
这哥们儿先吐槽了咱们做游戏经常犯的错：只盯着单一游戏看数据，脑子容易炸。为了解决这个问题，他们用了 AppAny 这种商业智能平台，提取了一个叫 亲和力 (Affinity) 的概念。简单说，就是两个游戏玩家重叠的概率。比如游戏 A 和 B 的亲和力是 4，那玩 A 的人就有 4 倍可能性去玩 B。光有数据不行，还得看得懂。他们用了个物理里常用的 Force Atlas 算法 (Force Atlas)，模拟引力，让相似的游戏自动聚在一起。结果出来一个图，不是按传统的分类，而是按玩家真实喜好排的。像糖果传奇这种大头牌，因为受众太广像香草冰淇淋一样，反而离具体类别很远；而像堡垒之夜或者老虎机，玩家圈子就纯粹得多。

接下来重点是造游戏的四块积木：核心玩法 (Core Gameplay)、元层级 (Meta Layer)、主题和艺术风格。这里头最坑的是元层级，也就是长期的成长目标。举个例子，花园故事一开始是做寻物的，后来加了解谜玩法，但数据告诉它跟资源管理类游戏的玩家更亲。这说明哪怕你有了解谜核心，如果元层级和资源管理搭在一起，就能蹭到更多资源玩家的流量。而且搭配比例很重要，不能随便堆砌。还有主题也很关键，硬核的主题吸引付费好的小圈子，轻松的主题赚大钱但转化难。至于艺术风格，有时候比玩法更能留住人，比如二次元画风能让换装游戏和 RPG 吸引到同一拨人。

最后给小厂兄弟支几招。别觉得自己没 King 那么大预算就用不了这套理论。你可以去应用商店推荐位看看关联推荐，拿社交媒体上的反馈来估算亲和力。在写代码前，先做个假页面测试概念，这就叫 Zero Moment of Truth（零时刻真相）。验证完再动真格的。投放广告时，也别一刀切，盯着特定元素去找有亲和力的人群。归根结底，不管技术多牛，还是得把玩家放第一。用 Quantic Foundry 框架 (Quantic Foundry Framework) 分析下玩家动机，搞清楚是为了爽还是为了成就感。最后算账也要算好，确保 生命周期价值 (Lifetime Value) 大于 单用户获取成本 (Cost Per Install)，这波才能稳稳落地。

## The 'Flappy Bird' that Laid the Golden Egg: Success in Hyper-Casual
- **Speaker:** David Fox (Double Coconut)
- **Duration:** 27 分钟
- **Category:** Mobile Summit
- **Video Page:** https://www.gdcvault.com/play/1025656
- **Slide Page:** 
- **Custom ID:** 1025656

### Overview
Hyper-casual games are one of the (few) viable success stories in mobile gaming this year. To an outsider, these titles may look like cloned, low-quality schlock. But, much like the pop music industry, success in hyper-casual involves an extremely polished nugget of gameplay wrapped in carefully calibrated image and shared with the world via a well-established but very-hard-to-enter distribution model. This session will pull back the curtain and look at how this all really works and where quality really matters.

### Content Summary
[TLDR]
超休闲游戏靠海量试错和流量套利赚钱，本质是手游界的“流行音乐制造机”。

[Background]
这哥们现身说法，扒开了超休闲游戏的内幕逻辑。讲明白咋样靠简单的玩法加广告变现，还能精准算账赚钱。适合想抄作业、懂点数据或者打算做发行的兄弟看看，省得瞎忙活。

[Recaps]
最早火的是《Flappy Bird》，虽然代码简单得像玩具，但凭着一股纯粹的心流体验，让用户停不下来，下载量直接干到五千万。后来大厂们学聪明了，把这种简单机制发挥到极致，搞出了不需要教程、单手可操作的超休闲游戏 (Hypercasual Games)。从最早的付费关卡变成现在的免费游玩 (Free-to-Play) 模式，核心就是降低门槛，让玩家一秒钟就能上手。

赚钱的核心逻辑其实是个数学题。你花在广告上砸给用户获取 (User Acquisition) 的钱，必须小于玩家贡献的价值。现在的套路全靠`奖励视频广告 (Rewarded Video Ads)`变现，所以`日留存率 (Retention)`就成了生命线。如果第一天走了大半人，基本可以判定这游戏要赔钱；如果能留住一半人，按播放次数算下来，通常能跑出正数利润。只要流水覆盖不了成本，立马止损，别纠结情怀。

为了最大化效率，公司一般采用“打群架”的策略。一口气做出一百个游戏原型，先扔出去做小范围测试，看看哪些数据好，再集中火力推广那几个能盈利的。像 Voodoo 这种巨无霸，手里握着一堆爆款，既能压价还能用自己的游戏网络互相导流，进一步拉低`单次安装成本 (CPI)`。这就跟流行音乐行业似的，一首神曲背后可能是几百首被废弃的半成品，只有经过`A/B 测试 (A/B Testing)`证明受众最喜欢的才值得大规模宣发。

最后大佬给了两个预测，挺扎心但也真实。一个是说以后可能连玩法都由`人工智能 (Artificial Intelligence)`自动生成，拼数据生成的怪物可能会更离谱更赚钱。但另一个预测是，这路走不远，玩家早就审美疲劳了。等到同质化严重到一定程度，还是得靠剧情、社交系统和深度玩法才能留住人，毕竟大家都懒得一直当手速机器，真正的乐趣还得靠内容硬撑。

## Social Depth of Location-Based Play in 'The Walking Dead: Our World'
- **Speaker:** Markus Montola, Sulka Haro (Next Games, Next Games/Nightscout)
- **Duration:** 56 分钟
- **Category:** Mobile Summit
- **Video Page:** https://www.gdcvault.com/play/1025937
- **Slide Page:** 
- **Custom ID:** 1025937

### Overview
The 'Walking Dead: Our World' is a simple location-based game about shooting walkers in your real environment. As the player learns the ropes, however, seemingly small layers of decision-making depth are added on the simple core loop. As the map location provides players with opportunities, and resource limitations restrict their choices, the players need to balance opportunities and risks to optimize their gameplay. Several novel social mechanics create this smart depth, including player-created buildings persisting in location, complex 25-player challenges where players need to play their strengths, and flares that allow players limited movement on the map.

### Content Summary
[TLDR]
死磕原型设计，砍掉繁琐的地点玩法，把 FPS 做成随时随地能玩的强社交生存游戏。

[Background]
Next Games 团队复盘了《行尸走肉：我们的世界》开发历程，重点解决地点类游戏 (Location-Based Games)“为了走路而走路”导致的体验割裂问题。对于想做 LBS 手游或强社交产品的制作人来说，这份关于如何平衡物理移动与游戏深度的实战经验非常有参考价值。

[Recaps]
本次分享的核心在于如何处理地点类服务的先天缺陷。开发组起初想复刻宝可梦式的收集玩法，但发现去“加油站”补给太像逛景点，不符合丧尸 IP 的生存紧张感，于是决定回归射击本质。关键一步是利用 Google 的兴趣点 (POI) 数据实现确定性内容生成，确保所有玩家看到同一张图，建立 共享现实 (Shared Reality)。这样朋友间才能看到同一个僵尸刷新点，避免了“我看到的和你不一样”的尴尬局面，这是做多人在线的基础设施。

核心循环 (Core Loop) 被刻意精简为“咬一口大小”，战斗只有 15 秒，扫荡资源虽多但库存上限低，迫使玩家不断消耗。最绝的设计是支持“沙发模式”，哪怕玩家坐在家不动，通过 公会系统 (Guild System) 也能参与全局进度，确保无论在哪都能玩出味道。开发初期曾尝试基于位置的协作任务，但因难以预测玩家密度导致竞争失衡，最终果断砍掉。改为以 公会任务板 (Guild Board) 为核心，类似宾果机，全球玩家共同完成行/列任务解锁奖励，彻底解决了物理位置带来的协作门槛。

最后总结了一大堆血泪教训。第一，在 原型设计 (Prototyping) 阶段要敢死磕，他们花了 10 个月做大量无用功，只为证明哪些路不通，虽然痛苦但值得。第二，必须砍掉“心爱功能”(Darlings)，不要因 沉没成本 舍不得移除喜欢的策划案，如果不符合同款就不留。第三，经济模型假设玩家总是最优解，玩家的失误才是难度调节器。第四，玩法可以缝合，比如结合了《迪士尼 Tsum Tsum》的宾果盘逻辑，不必非要自研全套，找到可参考的语言很重要。这套设计最终实现了时间即进步，技能即深度的平衡，让玩家觉得每一分钟投入都有价值。

## Mobile Game Designers Notebook 2019
- **Speaker:** Alexander King, Eric Zimmerman, Kenny Dinkin, Nicholas Fortugno, Fawzi Mesmar (Independent, NYU Game Center, King, Playmatics, King)
- **Duration:** 50 分钟

### Overview
There are many game design topics that don't require an hour to discuss, but can be useful as tips, or food for thought, for seasoned mobile game designers. Part microtalk, part design review, the MGDN is the session at the GDC Mobile Summit where experienced mobile game designers pick somebody else's game, or a trend in mobile game design, and dissect it. This year, this session will discuss procedurally generated content using books in the public domain, fashion as an element of gameplay in a role-playing game, and players' feelings when they make purchases in mobile games.

### Content Summary
[TLDR]
通过形式主义打破性别偏见，优化免费玩体验，结合手工与程序化提升内容生产效率。

[Background]
行业内常因性别刻板印象限制题材，且滥用氪金损害玩家体验。本次分享提供了打破偏见的案例及良心商业化思路。

[Recaps]
第一个哥们儿 Nick 讲了《Love Nikki》，直指行业里认为“换装是给女的，打怪是给男的”这种性别本质主义 (Gender Essentialism) 是屁话。他展示这游戏表面是打扮娃娃，实际全是 JRPG (Japanese Role-Playing Game) 那套硬核套路，比如属性匹配战斗、技能 CD 冷却、还有等级评估体系。核心逻辑是形式主义 (Formalism)，也就是别管内容多软萌，只要系统好玩，女性玩家照样会沉迷数值策略。这就是在告诉大伙，别自我设限，把成熟机制往新受众上搬照样行。

第二位设计师 Fauzi 则专门吐槽了 F2P (Free-to-Play) 游戏的氪金设计乱象。很多老游戏为了卖钱硬搞 P2W 或付费墙 (Pay Wall)，让玩家觉得充钱像作弊，不充钱像冤大头。现在得换个思路：一是钱要花在刀刃上，比如《Fortnite》的战斗通行证 (Battle Pass)，充钱也得靠肝才值；二是让付费行为惠及他人，像《Dota 2》买年鉴能增加奖金池；三是尊重非付费用户，他们也是社区生态。总之别让玩家花钱感到羞耻，要让他们觉得这是为体验买单，不是被割韭菜。

最后 Lost Words 团队分享了怎么搞定海量文本内容。书里的字太多，光靠人手调关卡根本不可能。他们玩了一招“手工式程序化 (Artisanal Procedural)"，说白了就是关键的地方人把关，比如选书章节、定难度阶梯；具体的拼图生成、规则变动交给算法跑。这样既避免了纯程序化生成的机械感，又解决了内容量不足的问题。甚至还要考虑玩家自带的难度选择，比如想休闲点还是紧张点，两边都能照顾到，这才是真正的设计师该操的心。
