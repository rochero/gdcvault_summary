## Tips & Tricks for UV Mapping
- **Speaker:** Keith Self-Ballard ()
- **Duration:** 0 分钟
- **Category:** Visual Arts
- **Video Page:** 
- **Slide Page:** https://www.gdcvault.com/play/1022901
- **Custom ID:** 1022901

### Overview


### Content Summary
[TLDR]
UV 映射搞不好，纹理师就得疯；这份干货教你怎么省空间还不失真，让模型效率翻倍。

[Background]
现代 3D 制作虽强，但 UV 环节往往是瓶颈，极易导致工期延误。作者结合自身实战经验，专门针对游戏开发中的贴图难题，提供了一套能省时间又保质量的操作套路，适合想提升工作效率的 3D 美术同行阅读。

[Recaps]
基础打样里，常用的映射方式有平面、盒子、球体和圆柱四种。其中圆柱最适合手脚躯干这类圆柱体结构，而球体在极点容易失真，收缩包裹基本可以弃用。做 UV 映射 (UV Mapping) 最关键的还是关注像素密度 (Pixel density)，千万别让贴图被拉伸或扭曲，否则最终渲染出来全是废片，浪费资源不说，还让贴图工人抓狂。

优化阶段主要看接缝 (Seams) 管理和空间利用。有机生物尽量做连续映射以减少接缝数量，机械物体则要保证平整无变形，Logo 方向要对齐水平轴。还能通过镜像对称减少工作量，或者把重复部件重叠映射来节省显存。对于地形等大面积区域，可以利用平铺纹理 (Tiling textures) 搭配混合图，既省电又能保持细节丰富度。

进阶玩法还要考虑后期特效配合，比如给水流或坦克履带排版时，要根据流动方向调整 UV 走向，这样加上着色器特效 (Shader FX) 后看起来才真实。此外，还可以引入多层细节纹理 (Detail textures)，根据距离远近自动叠加高频纹理，用小尺寸图片模拟高清质感。最后推荐个独门工作流：克隆模型拆散后单独映射，修复好后再合并导回原物体，既方便编辑又能保证数据准确。

## Outdoor Jungle Vegetation: Battlefield Vietnam
- **Speaker:** Rishi Bhattacharya ()
- **Duration:** 0 分钟
- **Category:** Visual Arts
- **Video Page:** 
- **Slide Page:** https://www.gdcvault.com/play/1022885
- **Custom ID:** 1022885

### Overview


### Content Summary
[TLDR]
DICE 利用分层模型和自动化脚本，在性能瓶颈下实现了《战地越南》海量植被的真实感与玩法平衡。

[Background]
面对新硬件环境下“画面好”与“跑得快”的矛盾，DICE 美术总监分享了如何用技术手段平衡《战地越南》的丛林生态，避免遮挡玩家视野或导致卡顿，适合做开放世界的美术和程序人员参考。

[Recaps]
这哥们是 DICE 的老牌美术，带着大伙复盘了当年做《战地越南》时的硬核操作。当时新引擎上了 DirectX9，开始支持逐像素法线贴图 (Per pixel Normal mapping) 和菲涅尔着色 (Fresnel shaders)，视觉效果确实爽，但问题也随之而来：满地图的树要把显卡烧穿了，怎么才算合理？核心就三点：别卡帧、别穿帮、让车辆能开。

为了解决“树多”这个性能炸弹，他们搞出了高低模交替的方案。近处的树用高面数模型，远处的直接切到低配版，关键还引入了集群树组 (Cluster trees) 把一群树当成一个物体渲染，极大地降低了顶点压力。最骚的操作是配合了脚本与位图 (Bitmap) 的自动布景工具，艺术家只需定义参数，再扔进去一张黑白掩膜图，系统就能根据 视距 (View Distance) 自动判断哪里该生草、哪里该留路，效率直接拉满。

底下的草丛（下层植被 (Undergrowth)）也是同理，为了防止草突然“蹦”出来破坏沉浸感，他们做了光影颜色的继承，让地面阴影能匹配树叶投影。不过实战中也踩了不少雷，比如树移动后地面重影要重新计算，或者植被太密直接把玩家藏进了“隐身模式”，导致找不到据点。这些排查出来的问题排查 (Troubleshooting) 干货，才是后来者真正值得抄的作业。
